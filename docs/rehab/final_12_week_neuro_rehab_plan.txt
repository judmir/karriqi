CASE FRAMING FOR THIS PLAN
The strongest current documented clinical consensus is functional movement disorder / FND, with left-sided movement/coordination symptoms. This plan does not try to overturn that. It keeps clinically important counterweights visible: early left tibial SEP/P40 delay, unilateral left-sided coordination pattern, and rehab observations that some movement-control difficulty appeared ataxic/non-distractible. Practical goal: improve function, document change, reduce confounders, and prepare better clinician conversations.

PRIMARY REHAB GOALS
1. Left hand: improve dexterity, typing confidence, buttons/shoelaces/bottle caps, guitar/piano-like fine movement.
2. Left leg: improve heaviness/coordination, stair descent, running tolerance, jumping/landing, football-specific control.
3. Speech/saliva: track and train speech effort, articulation, breath/voice coordination, saliva/swallow management.
4. Whole-body control: reduce right-side compensation and rebuild bilateral movement confidence.
5. Stress/fatigue sensitivity: learn which loads improve function and which trigger flares.
6. Clinician-useful evidence: create clean baseline and repeatable 4/8/12-week comparisons.

WEEKLY TRAINING STRUCTURE
Default week:
- 3x strength/coordination sessions, 45-60 min (Wednesday, Friday 18:00, Saturday)
- 2x fine-motor/OT sessions, 20-30 min (Tuesday longer; other days 10 min touch-ups)
- 2x speech/logopedics practice, 15-25 min
- 4x walking/cardio or running progression, 20-45 min (Monday, Tuesday, Thursday, Saturday easy)
- Sunday: easy walk only + weekly review (light mobility, no gym)
- 1-2x football-specific low-risk drills, 15-30 min
- Daily 5-10 min journal/checklist

Intensity rules:
- Start easier than ego wants.
- Increase only one variable per week: duration OR complexity OR intensity, not all three.
- If symptoms flare >2 points for more than 24-48h, reduce next session by 30-50%.
- Avoid boom-bust cycles.
- Sleep worsening is a sign to reduce load.

SIMPLE DAILY TEMPLATE

Daytime:
- complete scheduled session
- avoid maximal pushing if sleep/recovery poor

Evening, 5 min:
- fill symptom journal
- mark rehab done/partial/not done
- note trigger/context

12-WEEK CALENDAR

WEEK 1 — Calibration and safety
Goal: establish routine, no aggressive progression.
- Strength 2-3x: basic bilateral lower-body + upper-body control, slow tempo.
- Left leg: sit-to-stand, split stance weight shifts, step-ups low height, controlled stair practice.
- Left hand: buttons, coins, bottle cap, typing sample, slow finger sequencing.
- Speech: 2 short recordings; breathing + paced reading.
- Walking: 2 easy walks, no forced running.
- Football: ball taps/sole rolls/wall passes at slow pace only.
- Metrics: complete journal 5/7 days; no major flare.

WEEK 2 — Consistency
Goal: same tasks, slightly smoother execution.
- Strength 3x: add light resistance bands/dumbbells.
- Left leg: step-down practice low height, heel raises, balance with support.
- Left hand: increase fine-motor task duration by 10-20%.
- Speech: reading + spontaneous sample 2x.
- Walking: 2-3 easy walks.
- Football: 1-2 sessions slow cone dribble + wall passes.
- Metrics: adherence >=70%; identify first stress/sleep/symptom patterns.

WEEK 3 — Controlled progression
Goal: add coordination complexity.
- Strength 3x: single-leg supported work, cable rows/presses, loaded carries if safe.
- Left leg: lateral step, controlled knee alignment, slow eccentric step-down.
- Left hand: add bimanual tasks, guitar/piano-style finger patterns.
- Speech: paced speech, breath control, saliva check-ins.
- Cardio: introduce run-walk only if walking is stable: e.g. 1 min jog / 2 min walk x 6.
- Football: cone dribble, left/right foot passing, no sprint/contact.
- Metrics: compare stair descent feeling vs Week 1.

WEEK 4 — First retest week
Goal: repeat baseline tests and adjust.
- Reduce training volume by ~20% early week.
- Repeat hand, leg, speech, football videos using same protocol.
- Review data: sleep, HRV/recovery, stress, symptom scores, adherence.
- Strength remains 2-3x moderate.
- Cardio/running only if no flare.
- Metrics: Week0 vs Week4 comparison table.
- Decision: continue progression, hold, or deload.

WEEK 5 — Build phase 1
Goal: more dynamic left-leg control.
- Strength 3x: split squats supported, Romanian deadlift pattern, rows/presses, core anti-rotation.
- Left leg: step-downs, lateral control, mini hops only if safe and symptom-stable.
- Left hand: timed dexterity tasks, typing endurance, real-life tasks.
- Speech: add fatigue condition: short speech sample after light walk.
- Cardio: run-walk progression, do not chase distance yet.
- Football: controlled passing + dribbling, slight speed increase.

WEEK 6 — Build phase 2
Goal: improve tolerance without crashing.
- Strength 3x: small load increase if prior week tolerated.
- Left leg: dynamic balance, direction changes at walking speed.
- Left hand: 20-30 min OT/fine motor twice weekly.
- Speech: 2-3 sessions; monitor saliva/fatigue.
- Cardio: run-walk or brisk walking 2x.
- Football: 2 low-risk sessions, no competitive play.
- Metrics: watch for delayed flares 24h after training.

WEEK 7 — Complexity
Goal: combine strength + coordination + attention.
- Strength 3x: add dual-task elements cautiously, e.g. count backwards while stepping.
- Left leg: stairs down, slow eccentric knee control, lateral shuffle low speed.
- Left hand: task switching, left-hand precision under light time pressure.
- Speech: spontaneous speech practice, paced conversation if possible.
- Cardio: one longer easy walk and one interval session.
- Football: cone course + wall passes; track accuracy not speed.

WEEK 8 — Second retest week
Goal: repeat objective tests and prepare clinician summary.
- Repeat Week0/Week4 videos.
- Summarize: what improved, unchanged, worse.
- Compare wearable/journal patterns.
- If baseline labs were abnormal and doctor advised, consider follow-up timing.
- Review neurologist/physio/logopedics questions.
- Training: moderate only, no maximal push.
- Metrics: Week0 vs Week4 vs Week8.

WEEK 9 — Sport-specific control
Goal: bridge rehab to real-life football/running/stairs.
- Strength 3x: maintain progressive strength but avoid fatigue spikes.
- Left leg: landing mechanics, light plyometric prep only if safe.
- Cardio: run-walk toward continuous easy running if tolerated.
- Football: passing, dribbling, turning, light acceleration. No contact.
- Hand: focus on personally meaningful tasks: typing/guitar/piano/buttons.
- Speech: longer daily-life speech exposure; track effort.

WEEK 10 — Higher functional integration
Goal: more natural movement.
- Strength 2-3x depending on fatigue.
- Agility: low-amplitude direction changes, cone patterns, rhythm/metronome footwork.
- Running: maintain below symptom threshold.
- Football: controlled drills with friend if safe; still non-contact.
- Speech: conversation practice; monitor saliva/swallow.
- Metrics: can you do more without next-day crash?

WEEK 11 — Consolidation
Goal: stabilize gains before final retest.
- Reduce novelty.
- Keep best exercises only.
- Strength 2-3x moderate.
- Football/running only if stable.
- Practice exact retest tasks once, but do not overtrain them.
- Prepare final clinician summary template.

WEEK 12 — Final retest and next-cycle decision
Goal: compare, summarize, decide.
- Repeat full video/function protocol.
- Compare Week0, Week4, Week8, Week12.
- Generate 1-page summary for neurologist/physio/OT/logopedics:
  - adherence
  - improved functions
  - persistent limitations
  - symptom triggers
  - video links
  - lab follow-up status
  - questions
- Decide next cycle:
  A. Continue and progress
  B. Repeat with modifications
  C. Shift focus to speech/hand/leg
  D. Escalate specific clinician question

SUPPLEMENTS / NUTRITION — CLINICIAN-DISCUSSION ONLY
Do not start many things at once. Avoid making supplements the plan.

Reasonable to discuss:
- Vitamin D: prior value low-normal; continue sensible dose and recheck.
- Creatine: possible for strength/training support; discuss kidney/CK baseline; tell doctor because creatinine interpretation may change.
- Whey/protein: useful if tolerated and total protein is reasonable.
- Omega-3: optional; prior omega-3 index appeared good, so not urgent.
- Magnesium: possible if sleep/cramps, avoid excess.

Be cautious / avoid for now:
- Ashwagandha until thyroid pattern clarified, because FT4 was high with normal TSH and there are thyroid/liver cautions.
- Chronic high-dose B6 unless prescribed, because excess B6 can itself cause neuropathy-like symptoms.

Nutrition focus:
- Mediterranean/anti-inflammatory style.
- Hydration daily.
- Adequate protein distributed across meals.
- Reduce sugary drinks/fructose-heavy drinks.
- Keep alcohol at zero/very low; you already stopped for >1 year.
- Since uric acid was borderline/high: do not make it obsessive, but moderate frequent red/processed meat, organ meats, beer/alcohol, high-purine extremes, and dehydration.
- Track meals simply for 2-4 weeks, not forever.

TREMOR/VIBRATION QUESTION
Use this wording:
“I do not have a constant classic tremor, but I get situational vibration/shaking in certain postures or tasks. Would surface EMG/accelerometry or tremor polygraphy be useful to characterize frequency, regularity, entrainment, co-contraction, loading effect, or functional/organic features if we can provoke it during the test?”

STOP / DELoad RULES
Stop a session and reassess if:
- unsafe gait, near fall, or loss of control
- chest pain, breathing trouble, severe dizziness
- new neurological deficit
- true choking/swallowing danger
- pain that changes mechanics significantly
- symptom flare >2 points that persists next day

Deload next week if:
- sleep worsens for 3+ nights
- HR/recovery trend worsens and fatigue high
- symptoms flare after most sessions
- motivation drops because plan feels punishing
